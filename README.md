# Проекты

# Проектирование системы для food-delivery приложения
 
Выполнила тестовое задание из трёх связанных задач для мобильного приложения доставки продуктов
 
- Нашла 8 дефектов в исходном ТЗ (противоречия, избыточность, непроверяемые формулировки), сформулировала 6 уточняющих вопросов заказчику и переписала ТЗ в однозначном и тестируемом виде
- Спроектировала REST API метода получения списка магазинов-партнёров: пагинация, сортировка, полиморфная схема доставки, обработка ошибок, rate limiting
- Задокументировала API в формате OpenAPI 3.0
- Спроектировала архитектуру подсистемы push-уведомлений: регистрация device-токенов, доставка через Kafka, повторные попытки с нарастающей задержкой и DLQ
- Обосновала ключевые решения в 4 ADR: выбор брокера, структура очередей, схема данных, формат ошибок

[🔗 Ссылка](https://github.com/ksenia-komendar-sa/food-delivery-system-design)
