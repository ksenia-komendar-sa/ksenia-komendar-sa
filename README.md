# Приложение для управления умным домом

Описание: проектирование требований для мобильного приложения управления умными устройствами с поддержкой режима энергосбережения

- Проанализированы интервью с заказчиком и пользователями, выявлены требования

- Описаны критерии и сценарии приёмки
- Спроектирована ER-диаграмма на логическом уровне
- Разработана DFD на контекстном и логическом уровне
- Созданы интерактивные прототипы в Figma
- Составлены словарь данных и программа и методика испытаний
